# Siddhi Sikchi — Portfolio (React + Vite)

## Run locally
```bash
npm install
npm run dev
```
Open the printed local URL (usually http://localhost:5173).

## Build for production
```bash
npm run build
npm run preview
```
The production files are output to `dist/` — deploy that folder to Netlify, Vercel, GitHub Pages, etc.

## Edit your content
All personal data (name, bio, projects, certificates, hackathons, tech stack, socials) lives in one place:
`src/data/data.js` — edit that file to update the site without touching components.

Your profile photo is at `public/profile.jpg` — replace it with any square image of the same name to update it.
